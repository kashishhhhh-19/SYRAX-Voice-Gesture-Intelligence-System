# GestureFlow Assets Directory

This directory contains branding, user interface icons, architecture graphics, and presentation demo assets for **GestureFlow**.

## Structure

```
assets/
├── README.md              # Asset guide and checklist
├── screenshots/           # Application screenshots (placeholders provided below)
│   ├── dashboard_preview.png
│   ├── presentation_mode.png
│   └── tracking_hud.png
└── demo/                  # GIFs or short clips showcasing real-time gesture control
    └── live_demo.gif
```

## Adding Screenshots & Media to Portfolio

1. Launch GestureFlow locally:
   ```bash
   python main.py
   ```
2. Capture a high-resolution screenshot of the dashboard with hand tracking active.
3. Save the image into `assets/screenshots/dashboard_preview.png`.
4. The main [`README.md`](../README.md) is pre-configured to automatically link and render images placed in this directory.
